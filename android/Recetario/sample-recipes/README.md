# Sample recipes

`recetario-sample-recipes.zip` — 112 recipes with photos, curated by the app's author, in
Recetario's own backup format (the same one Settings → "Back up with photos" produces).

Not wired into the app (no first-run import, no bundled asset) — just a ready-made starter pack
for anyone setting up Recetario for the first time, or testing import/restore.

## Using it

In the app: Settings → "Import file" → pick this ZIP. Everything is reviewed before anything is
saved (see the main [README](../README.md#formats), "Import and restore") — nothing is
overwritten silently.

## Contents

Titles, ingredients and steps are in Spanish (the author's own collection, several originally
imported from recipe websites). Tags, servings and times are as entered; free-text notes were
cleaned up (removed scraping artifacts, fixed a couple of typos) but not rewritten — some recipes
have no notes at all, left empty rather than invented.
